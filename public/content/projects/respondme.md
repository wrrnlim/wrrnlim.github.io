RespondMe is a platform that allows users to manage and send out personalized RSVP invite forms, and manage users all in one place.

## Tech Stack

- **Framework:** Next.js
- **Languages:** TypeScript
- **Deployment:** Railway
- **Database & Auth:** Supabase
- **Styling:** TailwindCSS
- **Version Control:** Git + GitHub
- **Development:** VSCode
